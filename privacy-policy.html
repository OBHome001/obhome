มีผลบังคับใช้ตั้งแต่วันที่ 18 พฤษภาคม 2569

1. บทนำ

เราที่ OB HOME Materials ให้ความสำคัญกับความเป็นส่วนตัวของคุณ เอกสารนี้อธิบายว่าเรารวบรวม ใช้ และปกป้องข้อมูลส่วนบุคคลของคุณอย่างไร หากคุณมีคำถาม โปรดติดต่อเราได้ตามที่ระบุในหน้านี้

2. ข้อมูลที่เรารวบรวม

ข้อมูลที่คุณให้ไว้โดยตรง

  • ข้อมูลการสนับสนุนและการติดต่อ: ชื่อ, หมายเลขโทรศัพท์, ที่อยู่อีเมล, บันทึกการแชท (ผ่าน LINE, Facebook, หรือโทรศัพท์)
  • ข้อมูลบัญชี Admin: อีเมล, รหัสผ่าน, ประวัติการสนับสนุนระบบ (ถ้าเข้าสู่ระบบ admin)
  • ความเห็นและข้อเสนอแนะ: ข้อมูลใด ๆ ที่คุณส่งมาในเนื้อหาการติดต่อ

ข้อมูลที่รวบรวมโดยอัตโนมัติ

  • ข้อมูลอุปกรณ์: ประเภทเบราว์เซอร์, ระบบปฏิบัติการ, ที่อยู่ IP
  • ข้อมูลการทำงาน: หน้าที่คุณเยี่ยมชม, เวลาที่อยู่บนเว็บไซต์, ลิงก์ที่คลิก
  • ข้อมูลจาก Third-party: บันทึก Analytics จาก Google Fonts, Firebase, Cloudinary
💡 หมายเหตุ: เราไม่ใช้ cookies สำหรับติดตามทั่วไป แต่ Firebase อาจใช้ session storage สำหรับการยืนยันตัวตน

3. วิธีที่เรารวบรวมข้อมูล

Firebase Authentication

เมื่อคุณล็อกอินเป็น admin ข้อมูลล็อกอิน (อีเมล/รหัสผ่าน) จะถูกจัดเก็บใน Firebase Authentication ของ Google เรามี access ทางสถาบันเท่านั้น Google ไม่ได้ใช้ข้อมูลนี้เพื่อโฆษณา

Firebase Realtime Database

ข้อมูลสินค้า ลายผ้า และเนื้อหาหน้าเว็บจัดเก็บใน Firebase Realtime Database ปลายทาง: obhome-ceac3-default-rtdb.asia-southeast1.firebasedatabase.app สำหรับการแก้ไขจาก admin เท่านั้น

Cloudinary

เมื่อคุณอัปโหลดรูปภาพ พวกมันจะส่งไปยัง Cloudinary CDN สำหรับการจัดเก็บและการเสิร์ฟอย่างเร็ว Cloud ID: daiipuvsb Cloudinary มีแนวทางความเป็นส่วนตัวของตัวเอง - ดู cloudinary.com/privacy

4. วิธีใช้ข้อมูลของคุณ

  • ให้บริการเว็บไซต์: แสดงข้อมูลสินค้า อัปเดตเนื้อหา
  • การเข้าถึง Admin: ยืนยันตัวตน เข้าถึงแดชบอร์ด CMS
  • การสนับสนุนลูกค้า: ตอบสนองต่อคำถาม สัญญา LINE, Facebook, โทรศัพท์
  • การปรับปรุง: วิเคราะห์การใช้งาน ปรับปรุงเว็บไซต์
  • การปฏิบัติตามกฎหมาย: ปฏิบัติตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

5. การเก็บข้อมูล

ระยะเวลาการเก็บรักษา

  • ข้อมูลการสนับสนุน: 2 ปี (เลิกบริการ หรือตามคำขอ)
  • บัญชี Admin: ตราบเท่าที่บัญชีเปิดใช้งาน หรือตามคำขอ
  • ข้อมูลในฐานข้อมูล Firebase: ตราบเท่าที่ต้องการ หรือจนกว่าคุณร้องขอลบ
  • รูปภาพใน Cloudinary: ตราบเท่าที่ใช้งานจริง หรือตามนโยบาย Cloudinary
🔒 ความปลอดภัย: ข้อมูลทั้งหมดเข้ารหัสในระหว่างการส่ง (HTTPS/SSL) และจัดเก็บใน Google Cloud ของสิงคโปร์

6. การแบ่งปันข้อมูล

เราไม่เคยขายหรือให้เช่าข้อมูลส่วนบุคคลของคุณแก่บุคคลที่สาม ยกเว้น:

  • Google (Firebase): ใช้งาน Authentication, Database, Cloud Storage
  • Cloudinary: บริการภาพและ CDN
  • ผู้ให้บริการสนับสนุนทางกฎหมาย: หากจำเป็นตามกฎหมาย (เช่น การตรวจสอบทางกฎหมาย)

เราจะไม่เปิดเผยข้อมูลส่วนบุคคลโดยไม่ได้รับอนุญาต ยกเว้นตามที่กฎหมายกำหนด

7. สิทธิของคุณ

ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 คุณมีสิทธิ:

  • ขอเข้าถึง: ร้องขอสำเนาข้อมูลส่วนบุคคลของคุณ
  • ขอแก้ไข: ขอให้แก้ไขข้อมูลที่ไม่ถูกต้องหรือไม่สมบูรณ์
  • ขอลบ: ร้องขอการลบข้อมูล (ถ้าไม่จำเป็นทางกฎหมายอีกต่อไป)
  • ขอจำกัด: ร้องขอหยุดการประมวลผล
  • ขอย้าย: ขอข้อมูลในรูปแบบที่เป็นไปได้
